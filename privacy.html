PRIVACY POLICY

プライバシーポリシー

p.p製作所は、ユーザーのデータを必要以上に集めないことを基本方針としています。

1. 基本方針

p.p製作所は、シンプルで安心して使えるアプリを提供するため、ユーザーの個人情報や端末内データを必要以上に収集しません。各アプリは、可能な限り端末内で処理が完結するように設計しています。

2. 公式サイトについて

本サイトでは、アクセス解析、広告トラッキング、Cookieを利用した個人情報の収集は行いません。お問い合わせ等でユーザーから情報が送信された場合は、回答やサポート対応のために必要な範囲で利用します。

3. Media Memory Backup

Media Memory Backupは、写真、動画、音声などのメディアファイルを、ユーザーが指定した保存先へコピーするアプリです。バックアップ処理は端末内で行われ、メディアファイルの内容をp.p製作所のサーバーへ送信することはありません。

  • 写真、動画、音声ファイルへのアクセスは、バックアップ機能のために使用します。
  • コピー先の選択には、Androidのストレージアクセス機能を使用します。
  • クラウド送信、広告目的の利用、第三者提供は行いません。

4. VoxNote

VoxNoteは、録音、タイムスタンプ、文字起こし、音声整理を行うアプリです。録音データや文字起こしテキストは、原則として端末内に保存されます。p.p製作所が録音内容を収集することはありません。

  • マイク権限は録音機能のために使用します。
  • 音声ファイルのインポートは、ユーザーが選択したファイルに対してのみ行います。
  • 録音データ、文字起こしテキストを広告目的で利用しません。

5. カスタム電卓

カスタム電卓は、計算、式の表示、ボタン配置などを端末内で管理するアプリです。計算内容や設定情報をp.p製作所のサーバーへ送信することはありません。

  • 計算履歴や設定は、必要に応じて端末内に保存されます。
  • 広告トラッキングや外部送信は行いません。

6. 第三者提供

法令に基づく場合を除き、ユーザーの個人情報を第三者へ提供しません。

7. ポリシーの変更

本ポリシーの内容は、アプリの機能追加や法令変更に応じて更新することがあります。重要な変更がある場合は、本ページ上で告知します。
